# 果蝇1号 · DF-01 使用指南

适用版本：1.0.0；更新日期：2026-09-10。

## 启动与连接

Windows x64 用户可运行安装包，或解压便携包后启动 `df01-studio.exe`。目标电脑需要 Microsoft Edge WebView2 Runtime，便携包内的 `docs` 为随附说明。

1. 连接串口适配器与读卡模块，在工作台选择完整 COM 端口；列表会自动刷新，也可手动输入端口。
2. 填写模块当前 ID，出厂默认 `00`。通信固定为 115200 / 8N1、无流控。
3. 点击连接，等待完整配置同步完成后操作。同步失败时先核对端口、ID、设备接线及端口占用。
4. 没有实体设备时选择模拟器，可练习读写、换卡、配置及日志操作。模拟器不代表实卡认证或射频测试结果。

浏览器预览只提供模拟器；实体串口通过桌面程序访问。

## 读卡与自动上报

工作台显示卡号、卡片状态、实时通信及最近块的解码结果。可手动读取卡号，或选择模块自动读卡号 / 自动读块；每组设置需点击对应保存按钮。

自动读取由模块主动上报，应用不会循环发送读卡命令。自动读块需指定目标块或起始页。防重读设为 `0` 表示同 UID 无限期去重；`100–3000 ms` 表示间隔到期后在场卡片可再次上报。不同 UID 可立即上报。

收到新的成功自动上报时播放短提示音。顶部扬声器按钮控制全部声音，包括上报和彩蛋音效；静音状态会记住，取消静音不会补播历史上报。

卡号是协议提供的四字节数据；长 UID 仅提供末四字节，不能据此唯一识别所有卡片。同卡仅更新卡号时保留最近块内容，换卡或断开连接后清空。

## 数据块与密钥

数据块页左侧选择块和扇区，右侧编辑、读写与解码。块布局提供 64 块；页布局按起始页连续读取四页，共 16 字节。页号范围不代表实体卡容量。

支持 HEX、UTF-8、GBK、GB18030、ASCII、UTF-16LE、UTF-16BE 和 Base64。文字需先转换为待写字节并核对 16 字节预览，再确认写入。块 0 只读；扇区末块包含密钥与访问条件，写入需额外确认。整卡读取可停止，不会批量写入。

JSON 导入与导出使用 `df01-memory-v1`。导入文件只将当前选定块载入编辑器，不会直接写卡；导出排除扇区控制块。

密钥管理页分别输入 Key A / Key B，每组为 6 字节；也可选择相同密钥。输入和读回默认隐藏，装载成功后清空输入。密钥不存入本机偏好，日志与导出对密钥及控制块脱敏。

## 设备配置与日志

设备配置分为通信参数、模块自动方式、射频与防重读、会话选项四张卡片。更改 ID、自动模式、防重读或增益后，以成功响应及读回值为准；可点击刷新配置重新同步。断开连接不会重置模块配置。

通信日志支持方向与异常过滤、搜索、暂停显示、复制、`.log` 导出及清空。页面最多显示最近 200 条；桌面长日志在卡片内滚动，窄屏按记录分行显示。暂停显示不会停止串口通信。

点击日志工具栏的导出按钮，打开与当前主题一致的弹窗。可修改文件名、查看保存位置和内容预览，再点击“保存日志”。桌面版直接保存到系统“下载”目录，同名文件自动编号且不会覆盖；保存完成后显示完整路径。浏览器预览版由浏览器处理下载。文件为 UTF-8 编码的 `.log` 文本，包含 UTC 时间、收发方向、级别、命令和脱敏 HEX 报文，以及设备信息和筛选条件。导出固定为打开弹窗时的全部筛选记录；暂停时导出暂停快照，取消不会生成文件。

出现超时后连接会关闭，需检查设备后重新连接。写入或配置超时表示结果未确认；先读回核验，应用不会自动重发。

## 外观与窗口

外观页提供琥珀标本、苔原微光、夜航观测、高对比四主题，以及舒适 / 紧凑密度和动态效果选项。顶部日夜按钮在两组最近使用的主题之间切换。桌面外观页随窗口铺满首屏，窄屏自然滚动。

手动把增益滑条调到 7 档（48 dB）会触发白眼果蝇彩蛋：提示卡片与果蝇配色跟随当前主题，双眼保持白色；显示期间切换主题会立即更新。普通桌面窗口短暂抖动并回到原位，伴随振翅音效；最大化、全屏和浏览器使用整页抖动。启用减少动态效果后关闭抖动，静音按钮管理音效。彩蛋不会自动保存增益。

窗口默认 1280 × 820，最小 900 × 640；顶部提供拖动、最小化、最大化 / 还原及关闭。

## 本机设置与参考资料

当前应用标识为 `com.df01.studio`。从其他应用标识的版本更新后需重新设置主题、密度、动态效果及静音状态；安装不会自动迁移这些偏好或卸载此前安装。
