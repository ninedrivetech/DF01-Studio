## 界面与交互基线

- 密钥管理、设备配置、通信日志使用统一卡片、标题图标、控件尺寸与间距；桌面日志在卡片内滚动，窄屏按记录分行显示。
- 外观页适配 900 × 640、1280 × 820、1920 × 1080，四主题和两种密度均可铺满首屏；375 × 812、844 × 390 保留自然滚动。
- 当前完整浏览器回归已覆盖上述布局、长日志内部滚动、主题和密度切换。
- 自动读卡号 / 数据块上报播放短提示音，按日志 ID 去重、同批合并；手动响应、失败报文与历史上报不触发。全局静音立即停止声音，重载保留状态，恢复声音不补播。
- 普通桌面最高增益彩蛋实际移动窗口约 550 ms 并复位；最大化 / 全屏 / 浏览器使用整页动画。音效约 620 ms，减少动态效果时不抖动。

## 协议与数据基线

- `10/11/12/2B/2D/2E/2F/30/31` 帧向量、完整 `B1` 配置同步、固定 115200 / 8N1、拒绝 `2C`。
- 全帧体 `7F` 转义、分包、粘包、噪声、XOR、超时断开及未确认写入不重发。
- 新 ID 确认、实际增益读回、失败配置保护、有限与无限去重及手动同 UID 读取清除去重。
- 自动与手动目标冲突拦截，密钥与控制块脱敏，日志 / 缓冲有界。
- HEX、UTF-8、GBK、GB18030、ASCII、UTF-16LE/BE、Base64 转换与 16 字节写入读回，非法编码及草稿保护。
