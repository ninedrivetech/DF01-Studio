# DF-01 Studio 1.1.1

Windows x64 便携版；本次重新打包于 2026-09-27，版本保持 1.1.1。

作者：Mzee · xiemaths@outlook.com · 上海玖驱科技有限公司。

关于区域采用左右布局：软件名称与版本位于左侧，作者、公司及邮箱位于右侧；窄屏自动改为上下排列。

本次按 Flash v15 指令表完整适配电机上电方向：通过 `34/B4` 保存正转或反转，`31/B1` 在参数偏移33回读方向，兼容旧版配置。偷油婆扩展页提供独立“保存方向”按钮和已保存值，界面不显示 GPIO 名称。成功回包后同步配置，下次上电或复位生效，不立即切换当前输出；实际旋转方向取决于接线。旧固件未提供方向字段时禁用设置。果蝇仍不显示或进入扩展页。

语音、启动时序及初始占空比（默认 60%）继续按协议保存和回读。方向草稿切换语言时保留，离开页面后重新进入载入已保存值；失败回包不覆盖已保存配置。

统一中英文设备页布局与输入样式，补齐防重读范围提示，校验异常配置回包并在连接初始化失败后清理会话。Windows 便携打包不再依赖安装包，逐项校验程序和文档后生成 SHA256。

补齐 1.1.0 中缺失的偷油婆模拟器入口与原生自动化测试。

1. 连接方式选择“模拟设备”。
2. 在“模拟产品”中选择“果蝇一号模拟器”或“偷油婆一号模拟器”。
3. 点击连接，配置回读后自动进入对应工作站。

偷油婆模拟器支持 TTS 参数、启动时序、初始占空比和电机上电方向的保存和回读；选择本身不会提前切换页面。要切换模拟产品，先断开再选择并连接。真实串口设备的产品模式仍由实际配置回包决定。

自动化测试覆盖真实浏览器模拟器操作、原生 Rust 事务、WebView2 两产品切换和配置读写。原生测试从界面选择偷油婆并通过真实 Rust 服务运行 `31/B1`、`2E/AE`、`32/B2`、`33/B3` 和 `34/B4`，不替换 IPC 回包。最新结果见 `docs/VERIFICATION.md`。

模拟器不播放硬件语音，也不模拟物理缓启动或 Flash 掉电保存；这些项目仍需真实设备验证。
