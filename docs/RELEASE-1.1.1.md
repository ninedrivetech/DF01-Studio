# DF-01 Studio 1.1.1

Windows x64 便携版；本次更新于 2026-09-21。

作者：Mzee · xiemaths@outlook.com · 上海玖驱科技有限公司。

关于区域采用左右布局：软件名称与版本位于左侧，作者、公司及邮箱位于右侧；窄屏自动改为上下排列。

本次按 Flash v14 指令表更新语音、启动时序及初始占空比（默认 60%）。果蝇不显示或进入扩展页；偷油婆扩展页整合已保存参数与启动预览，电机正反转仅提供前端预选，离页重置，不发送任何电机控制命令。

统一中英文设备页布局与输入样式，补齐防重读范围提示，校验异常配置回包并在连接初始化失败后清理会话。Windows 便携打包不再依赖安装包，逐项校验程序和文档后生成 SHA256。

补齐 1.1.0 中缺失的偷油婆模拟器入口与原生自动化测试。

1. 连接方式选择“模拟设备”。
2. 在“模拟产品”中选择“果蝇一号模拟器”或“偷油婆一号模拟器”。
3. 点击连接，配置回读后自动进入对应工作站。

偷油婆模拟器支持 TTS 参数、启动时序的保存和回读；选择本身不会提前切换页面。要切换模拟产品，先断开再选择并连接。真实串口设备的产品模式仍由实际配置回包决定。

自动化测试新增真实浏览器模拟器操作、原生 Rust TTS 事务、Release WebView2 两产品切换和配置读写。原生测试从界面选择偷油婆并通过真实 Rust 服务运行 `31/B1`、`2E/AE`、`32/B2`，不替换 IPC 回包。

模拟器不播放硬件语音，也不模拟物理缓启动或 Flash 掉电保存；这些项目仍需真实设备验证。

本次发布文件：`DF-01-1.1.1-portable.zip`；校验值见 `SHA256SUMS.txt`。解压后运行 `df01-studio.exe`。
