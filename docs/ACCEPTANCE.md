# 软件验收与实机核验

当前固件权威依据为 `指令和参数表.md`（发布包内为 `command-table.md`）。规则及向量见 [PROTOCOL.md](PROTOCOL.md)，操作步骤见 [USER_GUIDE.md](USER_GUIDE.md)。本清单定义验收结果，不把未执行项目记为通过；模拟和浏览器验证不替代 Tauri 真实串口与模块验证。

当前版本的真实模块项目等待逐项实测。本文提供可填写的硬件验收模板，已执行的软件与原生窗口结果见 [VERIFICATION.md](VERIFICATION.md)。

## 1. 配置与交付

| 项目 | 通过条件 |
| --- | --- |
| Rust + Tauri 产物 | 生产构建成功，可启动，真实串口通过 Rust 后端访问；记录日志及可执行文件路径 |
| 串口与配置 | 固定 115200 / 8N1 / 无流控，地址 `00..FF`；连接后发送一次 `31`，用 `B1` 初始化配置 |
| 指令范围 | 支持 `10/11/12/2B/2D/2E/2F/30/31`；前后端均拒绝 `2C` 波特率修改 |
| 配置保存值 | `2B/2D/2E/2F/30` 收到成功响应后更新；`AD` 使用新地址，`B0` 返回实际增益 |
| 模拟设备 | 全部非交易操作可交互，明确模拟标志，含卡片状态、数据读写与可恢复错误 |
| 排除范围 | 无身份证、制卡、清卡、充值、扣款入口；后端阻止绕过；`A0` 标识不显示或导出 |
| 说明文档 | 包含使用指南、配置同步、UID 截断、页读取、整帧体转义及自动防重读说明；发布包中文档与当前源码一致 |

## 2. 协议与服务测试

- [ ] 最新指令表中读写、自动方式、新 ID、防重读、增益与完整配置向量编码、解码一致。
- [ ] LEN=`3+N`，XOR 包含地址，边界长度校验有效。
- [ ] **所有帧体 `7F` 双写**，包括地址、命令、参数、校验；覆盖 `7F0400116A7F7F`。
- [ ] 每个字节边界拆包、转义对中间拆包、多帧同包均正确解析。
- [ ] 噪声、错误长度、错误转义、错误 XOR、残帧可恢复，后续有效帧仍能解析。
- [ ] 成功 `90/92` 参数为 7 字节、`91` 为 23 字节、`B0` 为 2 字节、`B1` 为 27 字节；缺字段不作为完整结果。
- [ ] `AA BB CC DD` 为 `0xDDCCBBAA` / `3721182122`；保留原始 4 字节，说明可能是全 UID 末 4 字节。
- [ ] `FD` 密码错误、`FB` 卡片 CRC 错误、本地串口 XOR 错误分别处理。
- [ ] 允许模块当前 ID `00..FF`，拒绝非 115200、`2C` 和范围外命令；`AD` 仅按新 ID 成功响应确认变更。
- [ ] 连接后恰好一次 `31/B1` 同步；`B1` 正确解释小端波特率、RESET 值、两组密钥、自动配置和增益。
- [ ] `2F` 小端参数仅允许 0 或 100–3000 ms，拒绝 1–99 和越界值；`30` 仅允许 0–7。
- [ ] 设置失败不覆盖已保存配置，`30/B0` 使用响应的实际档位。
- [ ] 页布局允许起始页 `0..255`，返回连续 4 页共 16 字节；Classic 1K 块布局为 `0..63`。
- [ ] 自动模式 `00=读UID`、`01=关闭`、`02=读块/页`；10 字节参数校验与常量正确。
- [ ] 当前自动方式保留初始值不影响模拟行为，不作为间隔、金额或次数。
- [ ] RESET=0 时同 UID 无限期去重，移走放回仍不重复，另一 UID 成功后原 UID 可再上报；500 ms LED 定时不触发重复上报。
- [ ] RESET=100–3000 ms 到期允许在场同 UID 再次上报；每次成功 `2E/2F` 都会清除当前去重记录。
- [ ] 主动 `10/11` 不受去重限制；成功读取与去重记录相同的 UID 时清除记录，不同 UID 或失败不清除；自动失败不主动上报。
- [ ] 正常空闲时不周期发送 `10/11`，持续读卡由 `2E` 后的 `90/91` 被动上报完成。
- [ ] 超时、拔出、读写失败、取消和断开结束等待，同连接请求串行执行。
- [ ] 写入、密钥和配置超时不自动重发，明确未确认结果。
- [ ] 旧连接数据不污染新连接，主动上报可观察，记录无事务号导致的匹配限制。
- [ ] 密钥不进入日志、导出、持久化设置或异常信息；缓冲与历史记录有界。

| --- | --- |
| 启动与连接 | 首屏为工作台；未连接 / 连接中 / 真机 / 模拟 / 错误清楚区分，刷新、连接、断开有效 |
| 配置同步 | 连接后同步 ID、只读波特率、模式、块号、密钥、RESET 和增益；可手动刷新，界面与后端校验一致 |
| 实时工作台 | 首屏直接观察 TX/RX、命令、HEX、状态、时间和统计；过滤、搜索、暂停显示与报文复制有效 |
| 卡片识别 | 原始 ATQA、四字节 UID、小端数值完整，未知 ATQA 不臆造型号，UID 截断说明明确 |
| 块 / 页读取 | S50 块与 Ultralight / NTAG 页布局可选；页模式支持 `64..255`，回包按 4 页解释 |
| 批量读取 | 范围正确、进度准确、可取消，不以协议参数范围承诺芯片实际容量 |
| 读取编码 | 块和页可选 HEX、UTF-8、GBK、GB18030、ASCII、UTF-16LE、UTF-16BE、Base64；严格处理无效序列，切换视图不改变原始字节 |

| 写块保护 | 正好 16 字节，块 0 禁写，尾块独立确认；页模式不提供写入；读写目标和确认内容一致 |
| 密钥 | A/B 各 6 字节可不同，输入及读回默认掩码、确认和反馈完整；`2B/B1` 日志及导出脱敏 |
| 设备配置 | 固定 115200 只读；地址可改，RESET 和增益范围准确，超时不伪造变更成功 |
| 自动方式 | 模式 02 指定块 / 页，保留初始值不作为间隔，有限 / 无限防重读可核验；没有主机轮询入口 |
| 日志 | 发送 / 接收 / 状态 / 错误清楚，筛选、清空、导出有效，无密钥或排除身份标识；导出弹窗跟随主题，生成 UTF-8 `.log`，桌面保存到下载目录，同名自动编号，内容与打开弹窗时的筛选快照一致 |
| 多主题 | 琥珀标本、苔原微光、夜航观测、高对比四主题；页面 / 输入 / 弹窗一致更新，重启保留选择 |
| 页面一致性 | 密钥管理、设备配置、通信日志使用统一卡片和控件；桌面日志内部滚动，窄屏记录可读 |
| 外观首屏 | 900 × 640、1280 × 820、1920 × 1080 下主题、密度、动态效果及关于信息铺满首屏；窄屏自然滚动 |
| 上报提示音 | 新的成功自动 UID / 数据块上报提示，手动响应和历史上报不重播；顶部全局静音立即生效并持久化 |
| 增益彩蛋 | 手动调到 7 档触发窗口抖动并复位，配合振翅音效；最大化 / 浏览器整页抖动，减少动态效果时停用抖动 |
| 动画 | 状态、视图、通知有适度过渡，尊重减少动态效果设置 |
| 无障碍 | 图标有可访问名称，表单有标签，键盘焦点可见，状态不只依赖颜色 |
| 响应式 | 桌面与窄视口无重叠遮挡或意外横向滚动，长端口名 / 日志可阅读 |
| 原生窗口 | 系统标题栏隐藏，顶部状态栏与日间 / 夜间主题按钮同栏提供拖动、最小化、最大化 / 还原、关闭，无底部状态栏；最大化图标跟随系统状态，失败可恢复 |
| 平台文案 | 界面不展示“桌面版 / 手机版”字样；普通浏览器不显示原生窗口控制按钮 |
