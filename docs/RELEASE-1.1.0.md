# DF-01 Studio 1.1.0

发布日期：2026-09-11。Windows x64。

- 兼容新版固件的产品模式与 27 / 31 / 32 字节配置回包。
- 识别偷油婆设备后显示独立扩展页，自动切换为“偷油婆一号”，加入昆虫标识变换与页面过渡动画。
- 新增 TTS 编码、等待回传、读取块号设置，以及 PA5 缓升和系统启动延时设置。
- 修正手动读卡等待与防重读行为，隔离 U13T 原始语音帧，保留配置失败保护与密钥脱敏。
- 包含中英文切换、串口选择与工作台输入改进。

产品模式由设备固件决定，应用依据回读切换界面。没有产品模式串口写入命令。

验证：41 项 Rust 测试、130 项前端测试及产品扩展页浏览器回归通过。真实设备语音播报、启动时序与 Flash 保存仍需实机验证。

发布文件：`DF-01-1.1.0-x64-setup.exe`、`DF-01-1.1.0-portable.zip`，校验值见同目录 `SHA256SUMS.txt`。目标电脑需要 WebView2 Runtime。
