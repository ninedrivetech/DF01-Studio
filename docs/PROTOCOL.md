# 果蝇1号 · DF-01 协议与实现

当前固件依据为同目录 `指令和参数表.md`（Flash v15），发布包中名为 `command-table.md`。本文记录本应用的适配范围及校验向量。

## 通信与连接

- UART TTL，固定 115200 bit/s、8N1、无流控。地址为当前模块 ID，范围 `00..FF`，出厂 `00`。
- 连接成功后自动发送一次 `31`，收到有效 `B1` 后同步完整配置。没有成功读取配置的连接不作为已就绪连接返回。
- 后端允许 `10/11/12/2B/2D/2E/2F/30/31/32/33/34`。回读产品模式为 `00` 或 `01` 时均开放 `32` 与 `2E` 模式 `03`；产品模式不限制语音能力。果蝇保存和回读时序，但不执行启动延时或电机 PWM 缓升，也不配置 PA5/PA7 TIM 输出。固件兼容波特率命令 `2C` 不提供发送入口；`13..16/A0` 等未实现功能不提供操作入口。
- 每个连接串行发送请求，不循环发送 `10/11`；持续读取由模块 `2E` 自动模式提供。
- 超时及通信中断会关闭连接以防迟到响应误配。写入及配置超时表示结果未确认，不自动重发；读取配置超时属于查询失败。

## 帧格式

```text
7F | LEN | ADDR | CMD | PARAMS... | XOR
LEN = 3 + PARAMS.length
XOR = LEN ^ ADDR ^ CMD ^ 每个原始参数字节
```

LEN 为一个无符号字节，逻辑范围 `03..FF`。除最初帧头外，长度、地址、命令、参数和校验中的每个 `7F` 均编码成 `7F 7F`；先计算逻辑校验再转义。收包按字节流反转义、分帧及 XOR 校验，支持拆包、粘包和噪声恢复。长度与转义规则以当前表为准，不再沿用旧手册 `7E` 限制。

接收不依赖固定帧间隔，支持连续回包。接收缓冲、请求队列和日志有界。日志最多保留 1000 条。

## 命令与配置

| 功能 | 请求 → 响应 | 请求参数 | 成功响应参数 |
| --- | --- | --- | --- |
| 读卡 | `10 → 90` | 无 | 状态、ATQA(2)、UID(4) |
| 读块 / 页 | `11 → 91` | 块 / 起始页(1) | 状态、ATQA(2)、UID(4)、数据(16) |
| 写块 | `12 → 92` | 块(1)、数据(16) | 状态、ATQA(2)、UID(4) |
| 密钥 | `2B → AB` | Key A(6)、Key B(6)、`00 03 08 05 02 07` | 状态 |
| ID | `2D → AD` | 新 ID、`37 21 56` | 状态，成功响应使用新 ID |
| 自动方式 | `2E → AE` | 模式、模式+`0A`、块号、初始值(4)、`23 12 54` | 状态 |
| 防重读 | `2F → AF` | 毫秒值(2)，小端 | 状态 |
| 增益 | `30 → B0` | 档位(1) | 状态、实际档位 |
| 配置读取 | `31 → B1` | 无 | 共 27 / 31 / 32 / 33 / 34 字节参数，按版本解析 |
| 启动时序 | `32 → B2` | 缓升毫秒(2)、启动延时毫秒(2)，均小端 | 状态、实际缓升毫秒(2)、实际延时毫秒(2) |
| 初始占空比 | `33 → B3` | 百分数(1)，0–100 | 状态、当前保存的百分数(1) |
| 电机上电方向 | `34 → B4` | 方向(1)，00 或 01 | 状态、当前保存的方向(1) |

成功响应必须匹配完整负载长度；既有命令的非零状态可接受仅状态短帧。新增 `B4` 成功及失败均要求状态和合法方向两个字节。无匹配手动请求的 `90/91` 按自动上报处理；其他响应标记为未匹配应答。新 ID 设置成功只接受新地址 `AD`，失败响应仍按旧地址处理。

`91` 不携带块号或事务号。已启用自动读块且目标与手动读取不同时，底层拒绝发送该 `11`，避免把自动上报当作其他块的数据；应先关闭自动读块再读取其他目标。相同目标仍可执行手动读取。

`B1` 参数偏移：状态 `0`、ID `1`、波特率 `2..5`（小端）、模式 `6`、块号 `7`、保留值 `8..11`、Key A `12..17`、Key B `18..23`、防重读 `24..25`（小端）、增益 `26`。兼容 27、31、32 字节旧回包及 v14 的 33 字节参数；偏移 `27..30` 回读启动时序，新版偏移 `31` 的产品模式保存为 `productMode`（00 果蝇、01 偷油婆，旧回包为 null）。配置进入 `Snapshot.configuration`；仅在成功且结构有效的响应后更新已保存值。`B0` 使用实际返回的增益档位。

模拟设备默认：ID `00`、115200、模式 `00`、块 `04`、保留值 `01 00 00 00`、A/B 各 6 个 `FF`、防重读 `0`、增益 `07`（48 dB）、产品模式 `00`。模拟器使用支持的自动 UID 模式，不模拟固件默认模式 `03`。真实设备始终以 `31` 回读为准，不覆盖其已保存配置。增益档位 `00..07` 分别为 18、23、18、23、33、38、43、48 dB。

## 自动读取

- 常规页面提供 `00` 自动读卡号、`01` 关闭自动、`02` 自动读数据块。这三个模式不校验四字节保留值，设置时原样保留。仅“偷油婆扩展”页提供 `03` 语音模式，可设置块号、GB2312/GBK/UTF-16LE/UTF-16BE/UTF-8 编码与是否等待完成回传，保留最后两个字节。U13T 原始 `FD` 帧按长度跳过，文本内的 `7F` 不作为模块帧头；本应用不播放设备语音。

## 产品模式与扩展页

Flash v15 的 `B1` 新增参数偏移 `33`：`motorDirection`（00=PA7 固定低、PA5 PWM；01=PA5 固定低、PA7 PWM）。Rust 后端兼容 34 字节参数回包（LEN=25），旧回包此字段为 null，未回读方向时拒绝发送 `34`。两种产品均允许保存方向，成功 `B4` 按实际回传值同步，失败或无效回包不覆盖配置；保存值在下次上电或复位后用于硬件输出，不代表当前运行方向。原生和浏览器模拟器默认方向 00，均支持设置和回读。偷油婆扩展页显示正反转选项、已保存方向并提供独立保存按钮，不显示 GPIO 名称；旧固件方向控件禁用。切换语言保留草稿，离页后重新进入载入已保存值，周期性快照不覆盖未保存草稿。

Flash v14 的 `B1` 新增参数偏移 `32`：`initialDutyPercent`（0–100%）。旧回包此字段为 null，不提供 `33` 设置入口，底层也拒绝发送该命令。成功 `B3` 按实际返回值同步，失败或无效回包不覆盖已保存配置。模拟器默认时序为 2500/1000 ms、初始占空比 60%。偷油婆扩展页单独保存初始占空比，每条设置均等待回包；PWM 固定 20 kHz，不提供频率设置。初值 100% 表示启动即满。

模拟连接可通过 `simulationProductMode` 选择 `0` 果蝇或 `1` 偷油婆，默认 `0`。此参数仅决定模拟器配置，真实串口连接忽略它。偷油婆模拟器默认自动模式 `03`，通过正常 `31/B1` 链路回读后开放扩展页；模拟器验证配置读写，不播放语音或执行物理启动时序。

当前连接成功回读产品模式 `01` 后显示“偷油婆扩展”，自动进入页面并通过昆虫标识变换和淡入动画切换为“偷油婆一号”。回读 `00` 时恢复果蝇工作台，不显示或进入语音与时序扩展页；断开或旧固件没有产品模式字段时也不显示扩展页。动画尊重系统减少动态效果设置，周期性回读同一模式不会重复播放。

产品模式由固件编译和烧录决定，协议没有产品模式串口设置指令。界面切换不改写设备产品模式。扩展页将 TTS 与启动时序集中呈现：`32` 缓升范围 200–10000 ms、启动延时范围 200–5000 ms，仅成功且参数有效的 `B2` 更新已保存值；偷油婆下次启动生效。底层按新表允许果蝇保存、回读这些参数，但果蝇界面不提供设置入口，设备也不执行时序。`B1` 的 `27..28`、`29..30` 分别回读为 `rampMs`、`startupDelayMs`。
- 防重读时长为 `0` 或 `100..3000` ms。`0` 无限抑制同 UID；非零到期后清除 UID，卡片仍在场可再次上报。
- 不同 UID 可立即上报。仅移开再放回同 UID 不会清除无限防重读。
- 每次成功 `2E` 或 `2F` 都清除防重读记录，重复设置同模式也生效。
- 合法手动 `10/11` 登记时立即清除防重读，与卡是否存在、UID 是否相同无关。无卡、认证或读块失败时不返回错误帧，保留请求继续轮询；成功仅回报一次，不重新记录防重读。后续自动轮询仍可能再次上报。
- 应用对手动请求等待到配置的超时时长，并提示可能仍在等卡或认证；超时关闭连接以隔离迟到应答，不据此判定硬件断线。固件没有取消指令，断开上位机不撤销模块请求，重新连接后仍可能收到旧结果。
- 自动读卡错误静默，LED/TIM14 防重读计时由固件管理。上位机只设置参数和被动接收；模拟器复现这些可观察行为，不模拟物理射频和 LED。

## 卡片与写入

UID 只含末 4 字节，不代表完整长 UID；原始 `AA BB CC DD` 按小端显示为 `DDCCBBAA` / `3721182122`。ATQA 仅供初步识别。

Classic S50 范围为 `0..63`，每块 16 字节。当前上位机禁止写制造商块 0，写扇区尾块需额外确认；协议底层不会将用户的块号改成其他块。Ultralight / NTAG 读取接受起始页 `0..255`，返回连续 4 页共 16 字节，不支持用 `12` 写 4 字节页。页号范围不代表实际卡容量。

固件写块先用 Key A 完整认证及两阶段 ACK，失败后用 Key B 完整重试。`FD` 表示认证失败或 MIFARE NACK，`FE` 表示选卡、通信、读写、参数或 Flash 保存错误，`FF` 表示无卡；新版未定义 `FB`，按未知状态显示。`92` 错误回包仍含 7 字节参数，无卡时 ATQA/UID 为零；串口 XOR 错误在本地丢弃并单独记录。

`2B` 请求、`B1` 响应和扇区尾块内容在常规日志及预览中隐藏。密钥仅保留于会话配置内存，用于配置界面同步，不进入持久化偏好或日志导出。普通数据块保留帧内容以方便观察串口交互。
