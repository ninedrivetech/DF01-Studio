# 果蝇1号 · DF-01 协议与实现

权威依据为同目录的当前固件指令表：源码中为 `指令和参数表.md`，发布包中为 `command-table.md`。本文记录应用实现约束及校验向量。

## 通信与连接

- UART TTL，固定 115200 bit/s、8N1、无流控。地址为当前模块 ID，范围 `00..FF`，出厂 `00`。
- 连接成功后自动发送一次 `31`，收到有效 `B1` 后同步完整配置。没有成功读取配置的连接不作为已就绪连接返回。
- 仅允许 `10/11/12/2B/2D/2E/2F/30/31`。固件兼容波特率命令 `2C` 不提供发送入口；`13..16/A0` 等未实现功能不提供操作入口。
- 每个连接串行发送请求，不循环发送 `10/11`；持续读取由模块 `2E` 自动模式提供。
- 超时及通信中断会关闭连接以防迟到响应误配。写入及配置超时表示结果未确认，不自动重发；读取配置超时属于查询失败。

## 帧格式

```text
7F | LEN | ADDR | CMD | PARAMS... | XOR
LEN = 3 + PARAMS.length
XOR = LEN ^ ADDR ^ CMD ^ 每个原始参数字节
```

LEN 为一个无符号字节，逻辑范围 `03..FF`。除最初帧头外，长度、地址、命令、参数和校验中的每个 `7F` 均编码成 `7F 7F`；先计算逻辑校验再转义。收包按字节流反转义、分帧及 XOR 校验，支持拆包、粘包和噪声恢复。长度与转义规则以当前表为准，不再沿用旧手册 `7E` 限制。

模块相邻完整发送帧至少间隔 5 ms，不作为接收分帧依据。接收缓冲、请求队列和日志有界。日志最多保留 1000 条。

## 命令与配置

| 功能 | 请求 → 响应 | 请求参数 | 成功响应参数 |
| --- | --- | --- | --- |
| 读卡 | `10 → 90` | 无 | 状态、ATQA(2)、UID(4) |
| 读块 / 页 | `11 → 91` | 块 / 起始页(1) | 状态、ATQA(2)、UID(4)、数据(16) |
| 写块 | `12 → 92` | 块(1)、数据(16) | 状态、ATQA(2)、UID(4) |
| 密钥 | `2B → AB` | Key A(6)、Key B(6)、`00 03 08 05 02 07` | 状态 |
| ID | `2D → AD` | 新 ID、`37 21 56` | 状态，成功响应使用新 ID |
| 自动方式 | `2E → AE` | 模式、模式+`0A`、块号、初始值(4)、`23 12 54` | 状态 |
| 防重读 | `2F → AF` | 毫秒值(2)，小端 | 状态 |
| 增益 | `30 → B0` | 档位(1) | 状态、实际档位 |
| 配置读取 | `31 → B1` | 无 | 状态、配置(26) |

成功响应必须匹配完整负载长度；非零状态可接受仅状态短帧。无匹配手动请求的 `90/91` 按自动上报处理；其他响应标记为未匹配应答。新 ID 设置成功只接受新地址 `AD`，失败响应仍按旧地址处理。

`91` 不携带块号或事务号。已启用自动读块且目标与手动读取不同时，底层拒绝发送该 `11`，避免把自动上报当作其他块的数据；应先关闭自动读块再读取其他目标。相同目标仍可执行手动读取。

`B1` 参数偏移：状态 `0`、ID `1`、波特率 `2..5`（小端）、模式 `6`、块号 `7`、保留初始值 `8..11`、Key A `12..17`、Key B `18..23`、防重读 `24..25`（小端）、增益 `26`。配置进入 `Snapshot.configuration`；仅在成功且结构有效的响应后更新已保存值。`B0` 使用实际返回的增益档位。

配置默认：ID `00`、115200、模式 `00`、块 `01`、初始值 `00 00 00 01`、A/B 各 6 个 `FF`、防重读 `0`、增益 `04`（33 dB）。增益档位 `00..07` 分别为 18、23、18、23、33、38、43、48 dB。

## 自动读取

- `00` 自动读卡号，`01` 关闭自动，`02` 自动读数据块。初始值字段保留且固件不使用，不能当作定时参数。
- 防重读时长为 `0` 或 `100..3000` ms。`0` 无限抑制同 UID；非零到期后清除 UID，卡片仍在场可再次上报。
- 不同 UID 可立即上报。仅移开再放回同 UID 不会清除无限防重读。
- 每次成功 `2E` 或 `2F` 都清除防重读记录，重复设置同模式也生效。
- 手动 `10/11` 不受防重读限制。成功读取与记录相同的 UID 后清除防重读，允许随后再次自动上报；不同 UID 或读取失败不清除。
- 自动读卡错误静默，LED/TIM14 防重读计时由固件管理。上位机只设置参数和被动接收；模拟器复现这些可观察行为，不模拟物理射频和 LED。

## 卡片与写入

UID 只含末 4 字节，不代表完整长 UID；原始 `AA BB CC DD` 按小端显示为 `DDCCBBAA` / `3721182122`。ATQA 仅供初步识别。

Classic S50 范围为 `0..63`，每块 16 字节。当前上位机禁止写制造商块 0，写扇区尾块需额外确认；协议底层不会将用户的块号改成其他块。Ultralight / NTAG 读取接受起始页 `0..255`，返回连续 4 页共 16 字节，不支持用 `12` 写 4 字节页。页号范围不代表实际卡容量。

固件写块先用 Key A 完整认证及两阶段 ACK，失败后用 Key B 完整重试。`FD` 表示密钥或访问权限问题，`FE` 表示选卡、通信、ACK 格式或参数错误，`FF` 表示无卡，`FB` 表示卡片块 CRC 错误；串口 XOR 错误在本地丢弃并单独记录。

`2B` 请求、`B1` 响应和扇区尾块内容在常规日志及预览中隐藏。密钥仅保留于会话配置内存，用于配置界面同步，不进入持久化偏好或日志导出。普通数据块保留帧内容以方便观察串口交互。
